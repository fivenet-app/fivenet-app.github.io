## Übersicht

Der iOS-App "FiveNet Mobile" ist eine offene Community-Initiative rund um eine mobile App für FiveNet-Nutzer.
Es wird getrennt von der FiveNet-Webanwendung entwickelt und öffentlich auf GitHub verfolgt.

Der Hauptentwickler ist [PhilTec-Philip](https://github.com/PhilTec-Philip).

## Repository

Folge der Entwicklung hier: [github.com/fivenet-app/app-ios](https://github.com/fivenet-app/app-ios)
