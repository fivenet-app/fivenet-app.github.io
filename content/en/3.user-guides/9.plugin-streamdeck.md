## Overview

A StreamDeck plugin for FiveNet openly developed by the community for Elgato StreamDeck users.
It is developed separately from the FiveNet web application and is tracked publicly on GitHub.

The main developer is [PhilTec-Philip](https://github.com/PhilTec-Philip).
