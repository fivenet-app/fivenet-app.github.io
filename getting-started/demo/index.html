Demo

Try FiveNet using the public demo instance.

Try FiveNet in a live environment using the public demo instance.

Access the Demo Instance
The demo instance resets every 12 hours. During the reset, it may be unavailable for a few seconds, and some data may be cleared.

Login

Use the following credentials:

Username: demo
Password: fivenet-demo
Not every feature is fully available in the demo environment. Some advanced functionality may be limited or simulated.

Best Way to Explore

The demo account includes multiple characters. For the best overview, use the Los Santos Police Department (LSPD) character with the police job.

This character has access to superuser mode, which lets you:

  • Switch between jobs
  • Explore administrative features

You can enable or disable superuser mode from the user menu in the left sidebar.

If you want to explore as much of FiveNet as possible, start with the police character and enable superuser mode.
